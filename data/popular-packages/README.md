# Popular-package datasets

Reference lists of widely-used package names, one JSON file per registry.
The typosquat scanner (`src/typosquat/`) compares a candidate name against
these to decide whether it is imitating something popular. Each file is a
flat JSON array of 1000 lowercase names with no duplicates, ordered
most-downloaded first (the scanner uses position as a popularity rank),
embedded into the binary at compile time by
`src/typosquat/dataset.rs`.

| File | Registry | Source | Ranked by | Snapshot date |
| --- | --- | --- | --- | --- |
| `npm-top1000.json` | npm | [`npm-high-impact`](https://github.com/wooorm/npm-high-impact) ([`lib/top-download.js`](https://raw.githubusercontent.com/wooorm/npm-high-impact/main/lib/top-download.js)) | npm download count | 2026-10-16 |
| `pypi-top1000.json` | PyPI | [Top PyPI Packages](https://hugovk.dev/top-pypi-packages/) ([`top-pypi-packages.min.json`](https://hugovk.dev/top-pypi-packages/top-pypi-packages.min.json)) | Downloads over the last 30 days | 2026-10-16 |
| `crates-top1000.json` | crates.io | [crates.io API](https://crates.io/api/v1/crates?sort=recent-downloads&per_page=100&page=1) (`sort=recent-downloads`, 100 per page) | Downloads over the last 90 days | 2026-10-16 |

## Updating

The lists are regenerated by a standard-library-only Python script (3.9+).
Run it from the repository root:

```bash
python3 scripts/update-datasets.py            # all three registries
python3 scripts/update-datasets.py npm pypi   # just these (npm, pypi, crates)
cargo test --workspace --locked typosquat::dataset
```

For each registry the script:

1. fetches the source's ranking, most-downloaded first;
2. trims and lowercases each name, drops any that are invalid for the
   registry, and merges spellings the registry treats as the same package
   (for PyPI, after [PEP 503](https://peps.python.org/pep-0503/)
   normalisation);
3. keeps the top 1000 in rank order and writes them as a JSON array with two-space
   indentation and a trailing newline.

A file is only rewritten when its contents change, and the script prints how
many names were added and removed. Running it twice in a row produces no
diff. After an update, the dataset validation test in
`src/typosquat/dataset.rs` checks that every file is unique, trimmed,
lowercase and valid for its registry. Update the snapshot dates in the table
above when you commit new data.

## Notes on the sources

- **npm** has no official "most downloaded" endpoint. `npm-high-impact`
  ranks every package with more than a million weekly downloads by npm
  download count, and its maintainer refreshes it periodically. Downloads
  are dominated by transitive dependencies (`semver`, `ansi-styles`,
  `@babel/*`), so some well-known but less-downloaded direct dependencies
  (`vue`, `@angular/core`) fall outside the top 1000.
- **PyPI** data is published monthly from the PyPI download statistics, and
  names are already PEP 503 normalised (`typing-extensions`, not
  `typing_extensions`).
- **crates.io** counts update continuously, so two runs far apart can
  differ near rank 1000. The script makes at most one request per second
  with an identifying `User-Agent`, as the
  [crates.io data access policy](https://crates.io/data-access) asks.
  crates.io treats names case-insensitively, so they are lowercased.
