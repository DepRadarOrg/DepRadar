# Contributing to DepRadar

## Getting Started
1. Fork the repository
2. Clone: `git clone https://github.com/YOUR_USERNAME/DepRadar.git`
3. Create a branch: `git checkout -b fix/your-feature`
4. Make changes
5. Run tests
6. Commit: `git commit -m "fix: description"`
7. Push and open a PR

## PR Submission Checklist
- [ ] Code passes all CI checks
- [ ] Tests included for new functionality
- [ ] Documentation updated
- [ ] Commit messages follow conventional commits
- [ ] PR description references the issue (`closes #N`)

## PR Review Process
### Review Criteria
1. Correctness
2. Test coverage
3. Documentation
4. Code quality
5. Security
6. Backward compatibility

### Review Timeline
- Initial review: 3-5 business days
- Follow-up reviews: 2-3 business days

### Addressing Feedback
1. Read all comments carefully
2. Make requested changes
3. Push to same branch (do NOT close/reopen PR)
4. Re-request review

## Stellar Wave Bounty Process
1. Find issues labeled `Stellar Wave` + `good first issue`
2. Submit PR referencing the issue
3. On merge, bounty is paid via Soroban escrow + Drips
4. Add your wallet to PR description

## Questions?
Open an issue with the `documentation` label.
